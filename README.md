# Dr. Naveen Kumar — Academic & Research Website

Responsive static multi-page website prepared for GitHub Pages.

## Files
- `index.html` — homepage
- `about.html`, `research.html`, `projects.html`, `publications.html`
- `innovation.html`, `collaborations.html`, `teaching.html`, `contact.html`
- `styles.css`, `script.js`
- `assets/` — uploaded photographs, CHRIST logo and CV (where supplied)

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `naveen-kumar-website`.
2. Upload all files and folders from this package. Important: upload `index.html` at the repository root, not inside another folder.
3. Open repository Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your address will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/naveen-kumar-website/`
7. For a user/organisation site repository named `YOUR-GITHUB-USERNAME.github.io`, the address is:
   `https://YOUR-GITHUB-USERNAME.github.io/`

## Edit
Edit HTML files directly in GitHub or locally. Shared design settings are in `styles.css`.
